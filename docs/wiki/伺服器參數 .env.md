# 🎛️ 伺服器參數:`.env`

**所有** Palworld 參數(約 50 項)都集中在專案根目錄的 `.env`;每一項在 [`.example.env`](https://github.com/daniel840711/palserver-tools/blob/main/.example.env) 都有英文註解。改完存檔 → `restart.bat` 即套用。

## 分類速查

| 分類 | 代表參數 |
|---|---|
| 核心 | `TZ` 時區、`SERVER_NAME`、`SERVER_DESCRIPTION`、`PLAYERS` 人數、`PORT` |
| 密碼/存取 | `ADMIN_PASSWORD`(=RCON)、`SERVER_PASSWORD` 進服密碼、`PUBLIC_IP`、`USEAUTH`、`CROSSPLAY_PLATFORMS` |
| 難度/倍率 | `DIFFICULTY`、`EXP_RATE`、`PAL_CAPTURE_RATE`、`PAL/PLAYER_DAMAGE_RATE_*`、`PAL_EGG_DEFAULT_HATCHING_TIME` 孵蛋小時 |
| 世界限制 | `DROP_ITEM_MAX_NUM`、`BASE_CAMP_WORKER_MAX_NUM`、`GUILD_PLAYER_MAX_NUM`、`SUPPLY_DROP_SPAN` |
| 開關 | `IS_PVP`、`ENABLE_PLAYER_TO_PLAYER_DAMAGE`、`SHOW_PLAYER_LIST`、`IS_START_LOCATION_SELECT_BY_MAP` |

## 規則

- 倍率類 `1.0` = 官方預設;布林用字串 `True`/`False`
- **沒寫(或刪掉)的參數自動用預設值** —— `.env` 可以只放你想改的幾行
- `ADMIN_PASSWORD` 必須與 `backend/config.json` 的 `rcon.password` 一致(setup 腳本會自動同步;手動改要兩邊一起)
- ⚠️ 不要直接改 `PalWorldSettings.ini`:每次開機由 `.env` 重新產生(Docker 模式)

## 範例:把伺服器調成休閒風

```env
EXP_RATE=3.0
PAL_CAPTURE_RATE=2.0
PAL_EGG_DEFAULT_HATCHING_TIME=0.5
PLAYER_STOMACH_DECREASE_RATE=0.3
```
