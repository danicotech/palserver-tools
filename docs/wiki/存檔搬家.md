# 🚚 存檔搬家

系統只讀一個位置:`backend/palworld-data/`。存檔層級:

```text
backend/palworld-data/Pal/Saved/SaveGames/0/<世界GUID>/   ← 整個資料夾搬這裡
    ├── Level.sav        (世界主存檔)
    ├── LevelMeta.sav
    └── Players/*.sav    (每位玩家)
```

## 把既有伺服器搬進來

1. 兩邊伺服器都停止(`stop.bat`)
2. 找到原伺服器的 `SaveGames/0/<GUID>`:
   - Windows 專服:`PalServer\Pal\Saved\SaveGames\0\<GUID>`
   - Linux / Docker(同款映像):掛載目錄下同層級
3. 複製整個 `<GUID>` 資料夾到上面路徑
4. Linux 主機:`sudo chown -R 1000:1000 backend/palworld-data`
5. `start.bat` → 網站右上 🔄 重新載入,資料立即變成你的伺服器

## 與 [[SteamCMD 原生模式]] 互搬

| 方向 | 從 | 到 |
|---|---|---|
| 原生 → Docker | `native/server/Pal/Saved/SaveGames/0/<GUID>` | `backend/palworld-data/Pal/Saved/SaveGames/0/` |
| Docker → 原生 | `backend/palworld-data/.../0/<GUID>` | `native/server/Pal/Saved/SaveGames/0/` |

> ⚠️ 遊戲性設定不在存檔裡:Docker 模式改 `.env`(見 [[伺服器參數 .env]]);原生模式改 `PalWorldSettings.ini`。
