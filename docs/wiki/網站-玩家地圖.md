# 🗺️ 玩家地圖

在「🧑 玩家查詢」分頁,搜尋列下方就是玩家地圖。

## 圖上有什麼

| 標記 | 說明 |
|---|---|
| **圓形頭像** | 玩家的最後存檔位置。外框顏色 = 所屬公會;離線的會變灰 |
| **帕魯箱圖示** | 公會據點,外框同樣是公會色 |

滑過任一標記會顯示詳細資訊,**都附座標 x, y**:

- 玩家:名稱 · 在線狀態 / 公會 / 等級 · 帕魯數 / 座標
- 據點:公會名 · 第幾個據點 / 公會等級 · 成員數 / 座標

點玩家頭像會把該玩家帶進搜尋框,直接跳到他的卡片。

## 篩選

| 控制項 | 用途 |
|---|---|
| **全部 / 在線 / 離線** | 只看某一類玩家 |
| **公會據點下拉** | 選某個公會,只顯示該公會的據點與成員(選項會標出各公會有幾個據點) |
| **顯示據點** | 隱藏據點標記(標題的據點總數仍會顯示) |
| **在地圖上找玩家** | 輸入名稱或 UID 即時過濾標記 |
| **主世界 / 世界樹** | 兩張底圖常駐切換 |

## 頭像規則

玩家本身沒有頭像圖,所以從他擁有的帕魯裡挑一隻當代表 ——
以 UID 做穩定雜湊來選,所以**同一位玩家每次進站都是同一張臉**,
而且**地圖標記與玩家卡左上角用的是同一份規則**,兩邊一定一致。

## 據點資料從哪來

據點與公會來自存檔的 `GroupSaveDataMap` / `BaseCampSaveData`。
這兩段位於存檔尾段,解析較慢,所以後端用**獨立的低頻快取**在背景更新,
不影響帕魯資料的即時性。剛啟動時可能短暫看不到據點,稍等一輪即可。
