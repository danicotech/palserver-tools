# 🔄 自動更新

網站右上角的更新控制項(仿 Grafana / Loki)。

## 手動與自動

按鈕分左右兩半:

- **左半 🔄** —— 立即重新載入最新存檔資料
- **右半 ▾** —— 選擇自動更新間隔

可選:**手動(不自動更新) / 5 秒 / 15 秒 / 30 秒 / 60 秒 / 5 分 / 10 分**

啟用自動更新後按鈕會變成主題色,左半顯示**即時倒數**,一眼知道下次更新還有多久。

## 行為細節

| 情況 | 行為 |
|---|---|
| 選了某個間隔 | 立刻先更新一次,不用等第一輪 |
| 分頁切到背景 | 暫停倒數,不會在你沒看時堆積請求 |
| 上一次還在載入 | 不重複發送,倒數停在 1 秒,載完的下一秒立刻補上 |
| 重整頁面 | 設定存在瀏覽器,會保留你選的間隔 |

## 更新時畫面不會跳

更新採用「原地更新」:

- 舊資料留在畫面上,只有 🔄 圖示在轉,**不會被載入畫面取代**
- 地圖標記不是清空重畫,而是**平滑滑到新位置**,看起來像玩家在地圖上移動
- 更新失敗不會把畫面換成錯誤頁,維持舊資料

首次載入(畫面上還沒有資料)則顯示**骨架屏**,照實際版面佔位,
資料進來是「填上去」而不是整頁抽換,版面不會位移。
