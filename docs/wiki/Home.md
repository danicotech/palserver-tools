# 🐏 帕魯玩家查詢工具網 Wiki

一套 **Docker 一鍵部署**的 Palworld 伺服器全家桶:遊戲伺服器 + 自動排程開關服 + 玩家查詢網站。
本 Wiki 是完整使用手冊 —— 每個分頁、每個子功能都有截圖與操作步驟。
