# 🚀 安裝與一鍵啟動

## 三步驟開服(不用會任何指令)

1. **安裝 Docker**:Windows 裝 [Docker Desktop](https://www.docker.com/products/docker-desktop/) 並啟動;Linux `curl -fsSL https://get.docker.com | sh`
2. **下載專案**:GitHub 綠色 `Code` → `Download ZIP` → 解壓縮(或 `git clone`)
3. **啟動**:Windows 雙擊 **`start.bat`**;Linux/macOS `./start.sh`

第一次啟動會自動:

- 從 `.example.env` 產生 `.env`,**隨機生成管理密碼與進服密碼**(顯示在視窗,請抄下)
- 產生 `backend/config.json`(密碼同步、API token 隨機)
- 下載映像並啟動四個服務(見 [[Home]] 架構圖)

完成後:查詢網站 `http://localhost`;遊戲連線 `主機IP:8211`(UDP)。

## 日常操作

| 動作 | Windows | Linux/macOS |
|---|---|---|
| 啟動全部 | `start.bat` | `./start.sh` |
| 重啟(套用新設定) | `restart.bat` | `./restart.sh` |
| 停止全部 | `stop.bat` | `./stop.sh` |
| 狀態/日誌 | `status.bat` | `./status.sh` |

## Go 選單啟動器(選配)

裝好 [Go](https://go.dev/dl/) 後:

```bash
cd tools/launcher && go build -o ../../palserver.exe .
```

雙擊 `palserver.exe` 出現數字選單:1 啟動 / 2 重啟 / 3 停止 / 4 狀態 / 5 只更新網站。

## 對外公開

- 遊戲:路由器/防火牆開 **UDP 8211**
- 網站:自行架反向代理或隧道指向本機 80 埠(或加 gitignored 的 `docker-compose.override.yml` 疊加你的對外服務)
